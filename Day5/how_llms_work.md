# How LLMs Work in MitraMaati

## Pipeline Architecture Diagram
Prompt text ➔ Tokens (Sub-word units) ➔ Model (Transformer Neural Network Layers) ➔ Next Token Prediction probabilities

## Explanation
Large Language Models process input prompts by breaking text into tokens, mapping them to embeddings, passing them through self-attention transformer layers, and predicting subsequent tokens to formulate grounded soil advisory responses.
